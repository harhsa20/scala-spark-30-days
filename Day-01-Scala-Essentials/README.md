# Day 1 - Scala Essentials

## Overview

Day 1 covers the fundamental concepts of Scala programming and basic data processing using Scala collections.

## Topics Covered

- `val`, `var`, and `lazy val`
- Immutable collections
- `for`-comprehension and `yield`
- List, Vector, Set, and Map
- Traits
- Basic collection operations

## Exercises

### 1. Variables and Immutable Collections
- Practice `val`, `var`, and `lazy val`
- Work with immutable collections

### 2. For-Comprehension
- Use `for`-comprehension with `yield`
- Process student names and marks

### 3. Scala Collections
- Compare List, Vector, Set, and Map

### 4. Traits
- Create a `Logger` trait
- Implement the trait using two classes

### 5. Student Grade Processor
- Process student records using Scala collections
- Calculate grades based on marks
- Identify passed students
- Calculate average marks

## How to Run

Check the Scala version:

```bash
scala -version
```

Run an exercise:

```bash
cd 01-val-var-lazy-val
scala Main.scala
```

Each exercise can be run from its respective directory.
